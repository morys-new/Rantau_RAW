# Kisah Kampung: Life-Sim Prototype

A small life-simulation game that runs in the browser, built with plain HTML, CSS, and JavaScript (no libraries).

**Play online:** https://morys-new.github.io/Rantau_RAW/

## How it plays
- Each day has four time slots: morning, afternoon, evening, and night.
- Keep your money, energy, hunger, and happiness in balance.
- Work jobs (farming, waiting tables, construction) to earn money; jobs level up as you do them.
- Eat, rest, play, and build a relationship, while random events change your day.
- Goal: save enough to buy your dream house.

## About the project
This is the standalone prototype for **Rantau Stories**, a larger life-sim game planned with Next.js + Phaser.js on the frontend and Spring Boot + PostgreSQL on the backend.

## Project structure
```
index.html      game screen
css/style.css   styling
js/data.js      game state, places, and prices
js/game.js      game logic and events
```
